# SimpleVPN — VAULT Edition

اپلیکیشن VPN رایگان و بدون نیاز به کانفیگ برای اندروید — مبتنی بر شبکه Cloudflare WARP

## ویژگی‌ها

- بدون نیاز به کانفیگ، اشتراک یا فایل vless/vmess — فقط نصب کن و دکمه پاور رو بزن
- ساخت خودکار اکانت رایگان WARP در اولین اجرا (هیچ ثبت‌نامی لازم نیست)
- رابط کاربری تیره و شیشه‌ای «VAULT» با کره هولوگرافیک متحرک
- صفحه Nodes: ۸ کشور با پرچم، جست‌وجو و اندازه‌گیری پینگ واقعی هر منطقه (سرورهای مرجع واقعی در هر کشور)
- نوار پایین ۴ تب: Vault / Nodes / Stats / Config
- سنجه‌های زنده: دانلود و آپلود لحظه‌ای (Mbps)، زمان اتصال، حجم کل جلسه
- رمزنگاری WireGuard روی کل ترافیک، DNS داخلی 1.1.1.1

## کشورها

آلمان (فرانکفورت)، سوئیس (زوریخ)، هلند (آمستردام)، انگلیس (لندن)، سوئد (استکهلم)، فرانسه (پاریس)، آمریکا (نیویورک)، ژاپن (توکیو)

پینگ هر کشور با اتصال TCP واقعی به یک سرور مرجع عمومی داخل همان کشور اندازه‌گیری می‌شود — نه عدد ساختگی.

> نکته فنی: مسیر خروج WARP به نزدیک‌ترین دیتاسنتر Cloudflare اختصاص می‌یابد؛ انتخاب نود برای اولویت‌بندی و رتبه‌بندی تأخیر استفاده می‌شود.

## راهنمای نصب بدون ارور امنیتی

1. **موقع دانلود در مرورگر:** اگر کروم پیام «This type of file can harm your device» داد، روی **Download anyway** بزنید — این پیام برای تمام فایل‌های APK طبیعی است.
2. **اگر لینک گیت‌هاب ارور امنیتی/SSL داد:** از لینک میرور jsDelivr استفاده کنید.
3. **موقع نصب:** اگر اجازه نصب نداد → Settings → **Allow from this source** را فعال کنید.
4. **اگر Play Protect پیام «Harmful app blocked» داد:** **More details** → **Install anyway**. این برای هر برنامه‌ای خارج از گوگل‌پلی طبیعی است.
5. برنامه را باز کنید، از تب Nodes کشور را انتخاب و دکمه پاور را بزنید؛ در پنجره مجوز VPN گزینه **OK** را بزنید.

## ساخت از سورس

```bash
gradle assembleRelease
```

- minSdk: 24 (اندروید 7 به بالا)
- کتابخانه تونل: `com.wireguard.android:tunnel`
- بدون وابستگی به Firebase یا هر سرویس خارجی دیگر
