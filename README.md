# SimpleVPN

اپلیکیشن VPN رایگان و بدون نیاز به کانفیگ برای اندروید — مبتنی بر شبکه Cloudflare WARP

## ویژگی‌ها

- بدون نیاز به کانفیگ، اشتراک یا فایل vless/vmess — فقط نصب کن و دکمه «وصل» بزن
- ساخت خودکار اکانت رایگان WARP در اولین اجرا (هیچ ثبت‌نامی لازم نیست)
- انتخاب کشور خروجی: هلند، آمریکا، آلمان
- رابط کاربری فارسی
- رمزنگاری WireGuard روی کل ترافیک

## نصب

1. فایل `SimpleVPN-1.0.apk` را از بخش [Releases](https://github.com/mahyarsii11/SimpleVPN/releases) دانلود کنید.
2. روی گوشی، نصب برنامه‌های ناشناس (Unknown sources) را فعال کنید.
3. فایل را باز کرده و نصب کنید.
4. برنامه را باز کنید، کشور مورد نظر را انتخاب و «وصل» بزنید.

## ساخت از سورس

```bash
./gradlew assembleRelease
```

- minSdk: 21 (اندروید 5 به بالا)
- کتابخانه تونل: `com.wireguard.android:tunnel`

## سلب مسئولیت

این پروژه صرفاً برای استفاده شخصی و آموزشی منتشر شده و از سرویس عمومی Cloudflare WARP استفاده می‌کند.
