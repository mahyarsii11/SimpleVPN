# SimpleVPN

اپلیکیشن VPN رایگان و بدون نیاز به کانفیگ برای اندروید — مبتنی بر شبکه Cloudflare WARP

## ویژگی‌ها

- بدون نیاز به کانفیگ، اشتراک یا فایل vless/vmess — فقط نصب کن و دکمه «وصل» بزن
- ساخت خودکار اکانت رایگان WARP در اولین اجرا (هیچ ثبت‌نامی لازم نیست)
- انتخاب کشور خروجی: هلند، آمریکا، آلمان
- رابط کاربری فارسی
- رمزنگاری WireGuard روی کل ترافیک

## راهنمای نصب بدون ارور امنیتی

1. **موقع دانلود در مرورگر:** اگر کروم پیام «This type of file can harm your device» یا «فایل ممکن است مضر باشد» داد، روی **Download anyway** بزنید — این پیام برای تمام فایل‌های APK طبیعی است و ربطی به سلامت فایل ندارد.
2. **اگر لینک گیت‌هاب ارور امنیتی/SSL داد:** از لینک میرور jsDelivr استفاده کنید.
3. **موقع نصب:** اگر اندروید گفت «اجازه نصب از این منبع نداده»، روی Settings بزنید و گزینه **Allow from this source** را فعال کنید.
4. **اگر Play Protect پیام «Harmful app blocked» داد:** روی **More details** و بعد **Install anyway** بزنید. این پیام برای هر برنامه‌ای که از گوگل‌پلی دانلود نشده باشد ظاهر می‌شود.
5. برنامه را باز کنید، کشور مورد نظر را انتخاب و «وصل» بزنید؛ در پنجره مجوز VPN گزینه **OK** را بزنید.

## ساخت از سورس

```bash
./gradlew assembleRelease
```

- minSdk: 21 (اندروید 5 به بالا)
- کتابخانه تونل: `com.wireguard.android:tunnel`
